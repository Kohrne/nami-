Mode d'emploi & prérequis

Sur iPad : Safari et Chrome n'ont pas Web Bluetooth (limite WebKit). Utiliser le navigateur Bluefy – Web BLE Browser (gratuit, App Store) et ouvrir cette page hébergée en HTTPS (GitHub Pages). L'export passe par la feuille de partage iOS (Enregistrer dans Fichiers, AirDrop…).

Sur ordinateur : Chrome ou Edge, via http://localhost — par ex. python3 -m http.server 8000 dans le dossier, puis http://localhost:8000/.

Protocole de la 1ʳᵉ session de caractérisation (en ramant vraiment) : ① connecter, ② démarrer l'enregistrement, ③ ramer ~2 min régulier, ④ 30 s erratique volontaire, ⑤ s'arrêter 30 s sans toucher (observer pace/SPM à l'arrêt), ⑥ reprendre, ⑦ s'éloigner du rameur ou couper le moniteur pour provoquer une déconnexion, ⑧ exporter le JSON. Ce fichier devient la session de référence pour développer en replay.

Le format d'enregistrement (nami-session-v1) inclut les trames brutes (hex), le décodé, et un flux derived avec vitesse et position du bateau dans le temps — l'infra du futur ghost (Bloc 6).
